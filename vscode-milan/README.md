# Extensión experimental de Milán para VS Code

Reconoce archivos .milan, colorea palabras clave y añade el comando «Milán: Ejecutar archivo actual».

Para probarla, abre esta carpeta en VS Code y pulsa F5. En la ventana de desarrollo, abre el repositorio completo de Milán y ejecuta un archivo .milan desde la paleta de comandos.

Requiere Python y milan.py. Si no se encuentra el intérprete, configura milan.interpreterPath con su ruta absoluta; milan.pythonPath permite configurar Python.

**Estado:** prototipo sin validar en VS Code. No está publicada en Marketplace. No incluye depuración, autocompletado semántico ni Milán Studio. No ejecutes código no confiable.
